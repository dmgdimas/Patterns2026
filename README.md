# Автоматизация сети ресторанов "Ромашка"

Репозиторий содержит проектные материалы и базовые классы для разработки программного обеспечения автоматизации сети ресторанов "Ромашка" в соответствии с Техническим заданием от 28.11.2023.

## Описание доменов / сущностей

Ниже приведена таблица основных сущностей, подлежащих реализации в системе (Стек: Python 3.x, SQLite).

| Наименование сущности | Описание | Связи с другими сущностями |
| :--- | :--- | :--- |
| **Номенклатура** | Единица учета продукции (сырье, полуфабрикат, блюдо). | Связана с *Группой номенклатуры*, *Складом*, *Технологической картой*. |
| **Группа номенклатуры** | Категория для объединения элементов номенклатуры (для частичной инвентаризации). | Содержит множество *Номенклатур*. |
| **Склад** | Логическая единица для учета остатков продукции. | Привязан к *Помещению*. Содержит остатки *Номенклатуры*. |
| **Помещение** | Физическая локация (ресторан или производственный цех). | Содержит один или несколько *Складов*. |
| **Технологическая карта** | Описание состава и процесса приготовления (блюда или полуфабриката). | Ссылается на *Номенклатуру*. Может быть составной (ссылаться на другие *Технологические карты*). |
| **Сотрудник** | Работник компании (Производство, Обслуживание, Управление). | Привязан к *Графику работы*. Является ответственным за операции в *Складском*, *Финансовом* и *Оперативном* учете. |
| **График работы** | Расписание смен сотрудника с указанием длительности и правил оплаты (в т.ч. двойной тариф). | Связан с *Сотрудником*. |
| **Контрагент** | Юридическое лицо для ведения финансового учета. | Входит в *Группу контрагентов*. Участвует в *Финансовых документах*. |
| **Группа контрагентов** | Категория для объединения контрагентов. | Содержит множество *Контрагентов*. |
| **Финансовый документ** | Документ учета денежных средств (Поступление или Списание). | Связан с *Контрагентом*, *Типом оплаты* и *Сотрудником* (ответственным). |
| **Заказ** | Базовая сущность оперативного учета (Заказ на доставку, пополнение склада или производство). | Содержит *Номенклатуру*, привязан к *Ресторану* и *Сотруднику*. |
